# Car Brand Emblems

Transparent PNG brand emblems prepared for LMU's current manufacturer catalog.

Available files:
- `bmw.png`
- `ferrari.png`
- `lamborghini.png`
- `porsche.png`

Source assets are preserved in `public/brands/src/` and `public/brands/src/emblems/`.

Current emblem references:
- `BMW`: https://commons.wikimedia.org/wiki/File:BMW_Roundel.svg
- `Ferrari`: https://commons.wikimedia.org/wiki/File:Ferrari_F430_EngineLogo_Scudetto_rosso_noBG.png
- `Lamborghini`: https://superdevpro.com/brands/lamborghini
- `Porsche`: https://commons.wikimedia.org/wiki/File:Porsche_Warenzeichen.svg

Notes:
- Files were rendered locally to transparent PNG for app use.
- BMW and Porsche come from Wikimedia Commons vector sources.
- Ferrari comes from a transparent Wikimedia Commons PNG source.
- Lamborghini comes from an open icon library page exposed by SuperDev Pro / SVGCDN, not from Wikimedia Commons.
- These marks may still be protected by trademark rights even when the source file is marked as public domain, text-logo, or open-use by the provider.
